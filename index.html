GitHub Pages Setup

How it fits together

1 Set up your Git repo

Git turns your folder into a repository that remembers every version you save.

  1. Unzip the website template.

    So you get a normal folder you can work in.

    cd week43_assignment_template
    unzip html_css_template.zip

  2. Turn the folder into a Git repo.

    So it can remember every version you save.

    cd html_css_template
    git init

  3. Tell Git who you are. Change the text between the quotation marks " " to your own name and email.

    So every save is signed by you, and you only log in once.

    git config --global user.name "Your Name"
    git config --global user.email "you@example.com"
    git config --global credential.helper store

  4. Save your first version.

    So you have a snapshot of your site, ready to upload.

    git add .
    git commit -m "First commit"
Optional

Check that everything worked.

So you can see what Git is waiting for you to do next.

git status
  • Red file names? Use git add.
  • Green file names? Use git commit.
  • nothing to commit? Everything is saved.

2 Create a token

GitHub needs proof that it is really you uploading. A token is that proof.

  1. Click your profile picture (top right), then Settings.

  2. On the left, click Developer settings.

  3. Click Personal access tokens, then Tokens (classic).

  4. Click Generate new token, then Generate new token (classic).

  5. In Note, paste this name:

    dth_2026_website_token

  6. Tick repo.

  7. Scroll down and click Generate token.

  8. Keep this page open. You can only see the token once.

3 Push to GitHub

Your files are only on your computer. Pushing copies them to GitHub.

  1. On your repo page on GitHub, copy the line that starts with git remote add and paste it in the terminal. It looks like this:

    git remote add origin https://github.com/yourname/yourrepo.git

  2. Upload your files.

    So your site is stored online on GitHub.

    git push -u origin master

  3. Type your GitHub username and press Enter.

  4. Paste your token as the password and press Enter. Nothing shows while you paste. That is normal.

4 Publish with GitHub Pages

GitHub Pages turns your files into a website anyone can visit.

  1. On your repo page, click Settings.

  2. On the left, click Pages.

  3. Under Branch, change None to master.

  4. Click Save.

  5. Wait a few minutes. Your site will be at an address like this:

    https://yourname.github.io/yourrepo/

What happens when you change a file

Change your site

Your GitHub Pages site updates every time you push a new commit. You only need three commands: add, commit, push.

  1. Go into your website folder.

    So Git knows which repo you are working in.

    cd week43_assignment_template/html_css_template

  2. Change a file and save it.

    For example, change the heading in index.html, then press Ctrl+S.

  3. See what changed.

    Files you changed show in red.

    git status

  4. Get your changes ready to save.

    So they go into the next commit. In git status they turn green.

    git add .

  5. Save a new version. Change the text between the quotation marks " " to say what you changed.

    So your history shows what each change was.

    git commit -m "Change heading"

  6. Send it to GitHub.

    So GitHub has your new version. Git remembers your token, so you are not asked again.

    git push

  7. Check your site.

    Wait a minute or two, then refresh the page. Still the old version? Press Ctrl+Shift+R.

    https://yourname.github.io/yourrepo/
